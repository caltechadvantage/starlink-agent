# Starlink

## Touchscreen

The interface is laid out for the kit's Freenove 5" 800x480 panel in portrait, a 480x800 frame at about 7.4 px per mm. Renders and screen shares show it at roughly twice its real size, so judge sizes in millimetres on the panel:

- anything you tap is at least 64 px tall (about 8.6 mm), from `Theme.touch`
- text is at least 16 px (about 2.2 mm), apart from the crash log; body text is 20 px
- every tab fits on one screen without scrolling; when it does not, details move behind a switch rather than getting smaller
